# CSS (Cascading Style Sheet)

## 説明

CSS（Cascading Style Sheets）とは、Webページの見た目を設定するための言語です。
HTMLがページの構造を定義するのに対し、CSSは文字の色や大きさ、背景、レイアウトなどを指定し、HTMLで組まれた構造に装飾を加えて見た目を整える役割を担います。
HTMLだけで記述されたWebページは、単純なテキストや画像のみが並びます。しかし、CSSを使えば、文字の色やサイズ、レイアウトを自由にカスタマイズできます。
CSSをHTMLと分離して管理することで、デザインの修正や管理が簡単になる点も特徴です。

たとえば、私たちが普段利用しているAmazonやYahoo!ニュースなどのウェブサイトを想像してみてください。タイトルや見出しに色がついていたり、情報が縦横にきれいに並べられていたりするのは、すべてCSSの指示によるものです。
HTMLだけで記述されたWebページは、単純なテキストや画像が並ぶだけのシンプルなメモ書きのようになってしまいますが、CSSを使えば、文字の色やサイズ、レイアウトを自由にカスタマイズし、プロフェッショナルで使いやすいデザインを作り出すことができます。
